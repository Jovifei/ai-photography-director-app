# P1A Public Corpus License Review

Status: `SUPERSEDED_BY_P1A_REMEDIATION_REVIEW`.

The original attribution and per-source evidence were incomplete. The r2 validation requires an offline license-evidence file and source revision for every approved sample.

Every approved sample has a Wikimedia Commons source page and one explicitly accepted license identifier: `CC0`, `Public-Domain`, or `CC-BY-4.0`. The repository manifest preserves the page URL, license URL, author/attribution text, and original source hash for every record.

| License class | Approved use in P1A | Required preservation |
| --- | --- | --- |
| CC0 | Offline internal evaluation corpus | Keep source page and attribution record |
| Public Domain | Offline internal evaluation corpus | Keep source page and archive provenance |
| CC BY 4.0 | Offline internal evaluation corpus | Keep attribution, license URL, and modification record |

The source copies are external evidence, not Android assets and not Git content. No claim is made that the images are licensed for a later product release, public bundle, training, or redistribution without a separate legal/product decision. Any missing, changed, ambiguous, ShareAlike, NonCommercial, NoDerivatives, or non-public license is a fail-closed exclusion.
