# 摄影导演 Android Beta 用户指南

首次配置手机、Windows 本机 Qwen 服务、Private Wi‑Fi、一次性配对码和证书 pin，请先阅读：[Android Beta 手机配置与首次使用说明](ANDROID_BETA_PHONE_SETUP.md)。

## 无服务时也可完整使用的摄影流程

未连接本机分析服务时，App 仍可用于创建项目、通过系统 Photo Picker 私有导入最多 20 张参考图、筛选或删除照片、整理主参考、无 AI 指导拍摄、系统“另存为”和删除项目。

这不是本机 AI 分析模式：未完成可信 `READY` 的主参考不会带着固定示例建议进入 Camera Director。除了主动连接已准备好的本机服务，也可以由用户通过系统文件选择器导入符合 v1 契约的离线 Photo Knowledge Bundle；知识包只提供逐张结构化指导，不提供项目级语义汇总或模型推荐主参考。

## 一次完整流程

1. 打开“摄影导演”，创建拍摄项目。
2. 使用系统 Photo Picker 导入最多 20 张参考图；导入后只保留应用私有的去元数据副本。
3. 如已有获批的离线知识包，可选择“导入离线知识包”，通过系统文件选择器选择 JSON，再为每条知识明确绑定一张项目照片。App 不按顺序、文件名或路径猜测对应关系，也不会覆盖已有 READY 或分析中的照片。
4. 如需本机实时分析，选择“连接本机并逐张分析”，输入你主动选择的本机局域网地址、配对码和证书信息；没有配对时页面会显示不可用，不会伪造示例分析。
5. 配对成功后逐张开始分析。每张照片都有独立的 `QUEUED/RUNNING/READY/FAILED/UNAVAILABLE/CANCELLED` 状态；失败项可以单独重试。
6. 本机 Provider 可生成 READY-only 项目汇总；离线知识包 v1 只有逐张知识，页面会明确提示项目级语义汇总未提供，并由用户手动选择主参考。
7. 只有 READY 且带有效本机 Provider 或离线知识包来源记录的主参考可以进入 AI Camera Director；裸 READY、未分析或示例主参考始终进入无 AI 指导拍摄。
8. 拍摄完成后点击“保存照片”，使用 Android 系统选择器决定长期保存位置。取消或写入失败不会删除应用缓存，可稍后重试。
9. 在项目看板确认后删除单项或整个项目；删除项目不会影响其他项目。

## 你会看到的安全提示

- `示例指导 · 非图片分析` 只代表固定 Demo，不代表当前照片被分析，也不能作为实际 Camera Director 指导。
- Provider 不可用、网络失败、模型失败或 JSON 不合格时，页面只显示安全错误和计数，不复用旧结果。
- 离线知识包最多 512 KiB，只读取本次选择的无 BOM UTF-8 JSON；原始 JSON 和所选 URI 不落盘。SHA-256 证明结构完整性，不代表 App 已密码学验证生产者身份。
- 旋转、重启或恢复后，应用会先完成本地记录与私有图片 reconciliation，再展示项目内容。

## Beta 反馈

仅提交任务 PASS/FAIL、完成时间、1–5 分体验评分和脱敏问题描述；不要发送照片、URI、文件名、设备序列号、GPS、账号或原始 AI 文本。
