# 摄影导演 Android Beta 用户指南

首次配置手机、Windows 本机 Qwen 服务、Private Wi‑Fi、一次性配对码和证书 pin，请先阅读：[Android Beta 手机配置与首次使用说明](ANDROID_BETA_PHONE_SETUP.md)。

## 一次完整流程

1. 打开“摄影导演”，创建拍摄项目。
2. 使用系统 Photo Picker 导入最多 20 张参考图；导入后只保留应用私有的去元数据副本。
3. 在“配对本机服务”中输入你主动选择的本机局域网地址、配对码和证书信息；没有配对时页面会显示不可用，不会伪造示例分析。
4. 逐张开始分析。每张照片都有独立的 `QUEUED/RUNNING/READY/FAILED/UNAVAILABLE/CANCELLED` 状态；失败项可以单独重试。
5. 打开“项目汇总”。汇总只读取 READY 照片，展示共同方向、差异、最多三个强参考和推荐主参考。
6. 选择或覆盖主参考，进入 Camera Director；也可以选择无参考基础拍摄。
7. 拍摄完成后点击“保存照片”，使用 Android 系统选择器决定长期保存位置。取消或写入失败不会删除应用缓存，可稍后重试。
8. 在项目看板确认后删除单项，或确认清空全部项目。

## 你会看到的安全提示

- `示例指导 · 非图片分析` 只代表固定 Demo，不代表当前照片被分析。
- Provider 不可用、网络失败、模型失败或 JSON 不合格时，页面只显示安全错误和计数，不复用旧结果。
- 旋转、重启或恢复后，应用会先完成本地记录与私有图片 reconciliation，再展示项目内容。

## Beta 反馈

仅提交任务 PASS/FAIL、完成时间、1–5 分体验评分和脱敏问题描述；不要发送照片、URI、文件名、设备序列号、GPS、账号或原始 AI 文本。
