# 摄影导演 Beta 隐私说明

更新日期：2026-08-09

## 数据如何处理

- 参考照片通过 Android 系统 Photo Picker 选择后，会先生成去除 EXIF 的应用私有 JPEG；原始文件名、Picker URI、绝对路径和来源元数据不进入项目记录。
- 当用户主动配对本机服务并同意分析时，私有 JPEG 通过用户选定的私有局域网 HTTPS 连接发送到本机；不会上传到开发者服务器或公共云。Provider 按单张在内存处理，不保留输入图片。
- AI 推理使用本机离线 Qwen3-VL-2B。结果是辅助建议，不保证准确性；每张照片独立分析，项目汇总只使用 READY 结果。
- 拍摄照片默认短期保存在应用缓存。点击“保存照片”后由 Android 系统另存为选择器写入用户选择的位置；应用不申请 `READ_MEDIA_IMAGES`、`READ_EXTERNAL_STORAGE` 或 `WRITE_EXTERNAL_STORAGE`。
- 应用没有账号、广告、Analytics、公共云 API 或设备跟踪。用户可以删除单项照片或清空项目。
- Android 系统备份可能按系统/设备厂商策略同步到用户账号；应用无法保证系统云端副本即时删除。应用只将明确允许的项目数据库、私有派生图和必要偏好纳入备份规则，缓存/临时导入物不纳入。

## 权限

只使用相机权限和用户主动配对私有 LAN Provider 所需的网络权限。相机权限仅用于实时预览和拍摄；网络权限不用于公共服务或后台上传。

## Beta 边界

Beta 仅供受邀测试，当前不上传 Play、不组织公开分发。问题反馈不得附带照片、姓名、账号、设备 ID、GPS、URI、文件名或原始 AI 输出。
